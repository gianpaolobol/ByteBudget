# ByteBudget — approved direction
International tourist app: ivory/teal design approved in conversation. Budget per person, walking radius 100–1000 m, lunch/dinner, stable ranked results and detail/menu/navigation. Automatic local currency and price bands from city-level observed meal prices; do not invent worldwide fixed thresholds. No cuisine filters. Organic ranking cannot be purchased; sponsored offers separate and disclosed.
Implementation choice: installable responsive web app packaged with Capacitor for iOS/Android, plain ES modules to keep the first release small. No background tracking. Location only after explicit action. English/Italian interface. Provider-neutral restaurant dataset schema with explicit price provenance, freshness, city, currency and meal. Unknown prices do not qualify for a hard budget. Demo data isolated and labeled; unavailable production provider produces an honest empty state. Live data and store publication require provider credentials, trusted price data, signing and store access. No paid service activated automatically.
Alternative considered: Expo; Capacitor selected by implementer to share the approved web visual exactly across platforms. This is an implementation choice, not a prior user decision.
